อีกครึ่งคือข้อความไทยของคุณถูกนับเป็นกี่ token ซึ่งแต่ละค่ายนับไม่เท่ากัน ผมวัดเรื่องนี้กับ {{n_models}} โมเดล

"{{scenario}}" มีค่าใช้จ่าย {{pair1_a_thb}} บน {{pair1_a}} และ {{pair1_b_thb}} บน {{pair1_b}}
ต่างกัน {{ratio_price}} เท่า

ตัวเลขนี้มาจากคู่ประโยคไทย–อังกฤษ {{pairs}} คู่ของชุดข้อมูล FLORES-200 วัดเมื่อ {{date_data}}

({{counter_more_1k}} เทียบกับ {{counter_fewer_1k}} ต่อ 1,000 ตัวอักษร) เพราะราคาต่อ token ต่างกัน
ต้นทุนเป็นแค่ด้านเดียวของการเลือกโมเดล อีกด้านคือคุณภาพ ซึ่งต้องทดสอบกับงานจริงของคุณเอง

## Claude สองรุ่น: ภาษาไทยไม่ได้ใช้ token น้อยลง ภาษาอังกฤษใช้มากขึ้น

ตัวเลขที่มักถูกอ้างคือ "ภาษาไทยใช้ token กี่เท่าของภาษาอังกฤษ" ในโมเดลเดียวกัน จาก {{gen_old}} ไป {{gen_new}}
ค่านี้ลดจาก {{gen_old_premium}} เหลือ {{gen_new_premium}} เท่า ดูเหมือนภาษาไทยถูกลง
แต่จำนวน token ต่อข้อความไทย 1,000 ตัวอักษรแทบไม่เปลี่ยน ({{gen_old_thai}} → {{gen_new_thai}})
สิ่งที่เปลี่ยนคือฝั่งภาษาอังกฤษ ซึ่งเพิ่มจาก {{gen_old_english}} เป็น {{gen_new_english}} token ต่อ 1,000 ตัวอักษร

อัตราส่วนไทยต่ออังกฤษจึงใช้เทียบข้ามโมเดลไม่ได้ เพราะตัวหารของแต่ละโมเดลไม่เท่ากัน
ถ้าจะเทียบว่าโมเดลไหนใช้ token กับภาษาไทยน้อยกว่า ต้องดูจำนวน token ต่อตัวอักษรไทยโดยตรง

## โมเดลเปิดและโมเดลไทย

โมเดลเปิดไม่มีราคาต่อ token ของตัวเอง ค่าใช้จ่ายขึ้นกับเครื่องหรือผู้ให้บริการที่ใช้รัน
จำนวน token ของโมเดลกลุ่มนี้จึงมีผลกับความเร็วและพื้นที่ context ไม่ใช่บิลต่อ token โดยตรง
และผมรายงานเฉพาะจำนวน token

สิ่งที่วัดได้คือ โมเดลที่ต่อยอดจากโมเดลฐานจะรับ tokenizer ของโมเดลฐานมาด้วย กลุ่ม {{thai_group_label}}
({{thai_group_models}} โมเดลในชุดที่วัด) นับ token ได้เท่ากันทุกประโยค คือ {{thai_group_1k}} token
ต่อ 1,000 ตัวอักษรไทย ตารางของ tokenizer ทั้ง {{n_groups}} ตัว รวมโมเดลเปิดทุกกลุ่ม อยู่ในหน้าเว็บและ README

## ข้อจำกัด

- วัดต้นทุน token เท่านั้น ไม่ได้บอกคุณภาพคำตอบ
- ข้อความที่ใช้วัดเป็นแนวข่าวและสารานุกรม (FLORES-200) ข้อความแชท ชื่อสินค้า หรือภาษาปนอังกฤษ
  อาจถูกแบ่ง token ในอัตราที่ต่างออกไป
- token ขาออกสมมติว่าใช้อัตราเดียวกับข้อความขาเข้าของภาษาเดียวกัน งานนี้ไม่ได้วัดสิ่งที่โมเดลเขียนออกมา
- ไม่รวม prompt caching, ส่วนลด batch, thinking token และ token โครงคำขอ ใช้ราคาป้ายมาตรฐานเท่านั้น
- จำนวน token ของ Claude มาจาก endpoint `count_tokens` ผมตรวจกับยอดที่ถูกคิดเงินจริง {{bill_texts}} คำขอ
  แล้วตรงกันทุกคำขอ แต่การตรวจนี้ครอบคลุมเฉพาะคำขอที่มีข้อความเดียว ไม่มี system prompt ไม่มี tools
- ราคาเปลี่ยนได้ ณ {{date_prices}} หน้า pricing ของ Google ระบุวันสิ้นสุดของราคาปัจจุบันไว้แล้วสำหรับ:
